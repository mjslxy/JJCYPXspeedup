# 🎬 防暂停 + 倍速播放（Tampermonkey 脚本）

一个油猴（Tampermonkey）用户脚本，解决视频网站切窗口/切标签自动暂停的问题，并支持倍速播放。

## ✨ 功能

- 🛡️ 拦截切窗口、切标签、失焦导致的视频暂停
- ⚡ 支持 1~10x 倍速
- 🎛️ 油猴菜单一键切换倍速
- 💾 自动记忆你的设置
- 🔘 可随时开启/关闭防暂停

## 🚀 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击下方的 `防暂停 + 倍速（Edge）.user.js``基金业协会视频自动播放.user.js`
3. 点击 **Raw** 按钮
4. Tampermonkey 会自动弹出安装页面 → 点击安装

## 🎛️ 使用方法

1. 安装后刷新视频页面
2. 点击浏览器右上角油猴图标
3. 找到「防暂停 + 倍速播放」
4. 在菜单中选择你想要的倍速

## ⚠️ 注意事项

- 建议使用 4 倍速及以下，避免被网课平台检测
